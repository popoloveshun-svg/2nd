# Threads → Instagram リールへの一言（リール1本目）

前のセッションで決めたルール：
- 誘導だけの投稿は単独で出さない（実測でいいね率0.05%）。伸びた投稿の「自分の返信」として置く。
- Instagram のキャプションをそのまま貼らない。
- 1つの返信に誘導は1回だけ。

## A. 1本目（ジャパレスは逃げ？最初の一歩？）の返信欄に
```
本文に出てきた "Have here or takeaway?"、
レジで実際どう聞こえるかを12秒の動画にしました。
3秒考えてから答えが出る形です。

Instagram の @japares_english に置いています。
```

## B. 2本目（電話が聞き取れなかった話）の返信欄に
```
電話の英語はまだ動画にできていないのですが、
レジでいちばん最初に聞く一言を12秒にまとめました。
"店内？お持ち帰り？" 英語で言えるか、試してみてください。

Instagram の @japares_english にあります。
```

## C. 「言えそうで言えない5つ」を出したら、その返信欄に
```
①の答え "Have here or takeaway?" は動画にしました。
返事の聞き取り方（Dine in. など）も入れています。

Instagram の @japares_english で見られます。
```

## 使い方
- リールを Instagram に公開した後に入れる（先に入れると誘導先がない）。
- まず A を入れる。いちばん表示が多い投稿だから。
- B と C は、その投稿の表示が伸びているときだけ使う。
